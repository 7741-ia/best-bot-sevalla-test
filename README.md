## ⚙️ Features

- **Tag all group members** with the `.tagall` command
- **Admin restricted usage** (Only group admins can use certain commands)
- **Games** like Tic-Tac-Toe for interactive group engagement
- **Text-to-Speech** with `.tts`
- **Sticker creation** with `.sticker`
- **Anti-link detection** for group safety
- **Warn and manage group members** with admin control

---

## 📖 About

The Knight WhatsApp Bot assists group admins by providing them with tools to efficiently manage large WhatsApp groups. The bot uses the Baileys library to interact with the WhatsApp Web API and supports multi-device features.

It is lightweight and can be easily customized to add more commands as per your requirements. The bot runs in a Node.js environment and provides QR code-based authentication to link your WhatsApp account.

## 🛠️ Setup & Installation

This private copy adds a public WhatsApp pairing page and a password-protected administrator area at `/Best_bot_admin`. Each WhatsApp number runs in an isolated worker with separate authentication and data folders. See [DEPLOYMENT_FR.md](DEPLOYMENT_FR.md) for the Sevalla setup, persistent-volume requirement and private environment variables. Never add `.env` or live session data to GitHub.

### Prerequisites

- Node.js installed on your system
- Git installed (for cloning the repository)

### Step-by-Step Setup

1. **Clone the repository:**

    ```bash
    git clone https://github.com/7741-ia/best-bot-v33-multisession.git
    cd best-bot-v33-multisession
    ```

2. **Install the dependencies:**

    ```bash
    npm ci --legacy-peer-deps
    ```

3. **Configure chatbot AI providers (optional):**

  If this project already has a `.env`, do not overwrite it. This update preserves the existing `.env` and the API-key mapping in `config.js` exactly as in `main` for compatibility. `.env.example` is only a blank template for a fresh setup; prefer your hosting provider’s secret store for new deployments. Never paste secret values into chat or issues.

  `api/chat.js` requires a private `CHAT_API_TOKEN` of at least 24 characters. Set it in the local `.env` or hosting secret store before exposing the endpoint. Prefer authenticated `POST /chat` requests with a JSON body; authenticated `GET /chat?prompt=...` remains supported for compatibility but may expose prompts in URL logs.

4. **Run the multi-session website and manager:**

    ```bash
    npm start
    ```

5. **Connect an account:**

    Open the public site, enter the full international number and use the fresh pairing code in WhatsApp → Linked Devices → Link with phone number. For a one-off legacy run only, use `npm run start:single`; it does not use the new multi-session admin manager.
